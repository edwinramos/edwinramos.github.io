Welcome to my devlog. This is where I'll document my apps' progress, architecture decisions and day-to-day lessons as a .NET engineer.

## The stack (and why it costs $0)

- **Astro**: generates static HTML that is fast and easy for search engines to index.
- **GitHub Pages**: free hosting; GitHub Actions publishes every change automatically.
- **Pages CMS**: a visual editor that saves changes as commits to the repository.
- **Giscus**: comments and votes powered by GitHub Discussions.
